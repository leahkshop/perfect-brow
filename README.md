# Perfect Brow — 눈썹 밸런스 가이드 (웹앱)

PMU 아티스트용 눈썹 대칭·밸런스 가이드 도구.
브라우저에서 단독 실행되며 **서버가 필요 없습니다.** 사진은 기기 밖으로 나가지 않습니다.

### 🔗 https://leahkshop.github.io/perfect-brow/

> **현재 v1.28.0 · 회귀 테스트 95항목 전부 통과**
>
> 📌 **코드를 고치기 전에 반드시 [`BASELINE.md`](./BASELINE.md) 를 읽으세요.**
> 지키지 않으면 조용히 깨지는 규칙(좌표계·대칭·프리셋 저장소)이 정리돼 있습니다.
> 고친 뒤에는 `node regression-test.mjs` 로 **전 항목(95개)** 을 자동 검증하세요.
>
> 🤖 **AI 에게 이 프로젝트를 맡길 때는** [`클로드-시작-명령서.md`](./클로드-시작-명령서.md) 한 파일만 읽히면 됩니다.
> 작업 규칙·배포 절차·하지 말아야 할 것이 전부 그 안에 있습니다.

> **가로(landscape) 모드 · 양손 조작 기준으로 설계**되었습니다.
>
> ```
>  [ 왼손 ]        [        사진 (화면의 90% 이상)        ]  [ 오른손 ]
>   라인 선택 레일    위: 모든라인숨김·여러라인·밸런스 … 초기화   사진변경 → 다시실행 → 되돌리기
>   Eye/Front/…      아래 왼쪽: 프리셋 + 즐겨찾기 ★3        → 위아래 드래그 바 (오른쪽 중앙)
>                    아래 가운데: 사진저장 · 사진잠금       아래: 보정버튼 + 좌우 드래그 바
> ```
>
> 왼손 엄지로 조절할 바를 고르고, 오른손으로 그 바를 위아래(좌우)로 움직입니다.
> **v1.11.0부터 상단 바와 우측 패널을 없애고 모든 버튼을 캔버스 오른쪽·아래로 모았습니다.**

## 1. 사용하기

**이미 배포돼 있습니다.** 폰·태블릿에서 아래 주소를 열면 바로 씁니다.

### https://leahkshop.github.io/perfect-brow/

인터넷 없이 혼자 확인만 하려면 `perfect-brow-standalone.html` 을 더블클릭하세요 (전부 한 파일에 들어있는 버전).

## 2. 수정한 내용을 반영하기

1. 파일 수정 (`index.html` / `app.js`)
2. `node regression-test.mjs` → **95항목 전부 통과 확인**
3. `sw.js` 의 `VERSION` 올리기 (안 올리면 기기에 옛 화면이 그대로 남습니다)
4. 백업 zip + SHA-256 먼저 만들기
5. GitHub 저장소에서 `Add file` → `Upload files` → 해당 파일 덮어쓰기 → Commit
6. 릴리스 태그 발행
7. 약 1분 뒤 위 주소에 자동 반영 → 배포된 `sw.js` 버전으로 확인

로컬에서 먼저 보려면:

```bash
python3 -m http.server 8080     # 이 폴더에서 실행
# http://localhost:8080
```

## 3. 아이폰 / 아이패드 홈 화면에 앱으로 설치

1. **사파리**로 위 주소 열기 (크롬 아님 — 사파리여야 설치됨)
2. 하단 **공유 버튼** → **홈 화면에 추가**
3. 홈 화면에 나비 아이콘 생성 → 누르면 주소창 없이 전체화면 실행
4. **화면 회전 잠금은 켜둔 채로 그냥 눕히면 됩니다** — 앱이 알아서 가로로 나옵니다 (v1.8.0)

안드로이드는 크롬 **⋮ 메뉴 → 앱 설치**.

한 번 열어두면 **오프라인에서도 동작**합니다 (시술실 와이파이가 약해도 OK).

## 4. 사용법

| 기능 | 조작 |
| --- | --- |
| **선 옮기기** | 화면의 선을 **직접 잡고 끌면** 그 선이 움직입니다<br>`🔒 사진잠금` 을 켜면 **화면 아무 곳이나 끌어도** 선택된 선이 따라옵니다 (미세조정 모드)<br>가로 바는 위아래로만, 세로 바는 좌우로만 (대칭선은 좌우 대칭으로 함께) |
| 선 선택 | 왼쪽 레일 버튼 **또는 화면의 선을 직접 탭** — 탭해도 선이 밀리지 않습니다 |
| 선 미세조정 | **드래그 바 2개가 항상 떠 있습니다**<br>**위아래 바** — 오른쪽 끝 · 세로 한가운데. 위아래로 움직이는 가로 바 담당 (`▲` 위 / `▼` 아래)<br>**좌우 바** — 아래 · 오른쪽. 좌우로 움직이는 세로 바 담당 (`◀` 왼쪽 / `▶` 오른쪽)<br>지금 조작 대상인 쪽에 파란 테두리가 생깁니다 |
| 선 선택·표시 | 왼쪽 레일 색상 버튼 — **1번 탭 = 선택(움직일 수 있음), 같은 버튼 다시 탭 = 숨김/표시** |
| **여러라인** | 캔버스 왼쪽 위 `여러라인` — 켜면 선을 누를 때마다 **선택에 쌓이고**, 다시 누르면 해제됩니다<br>선택된 선은 모두 굵고 선명해지며 **드래그하면 함께 움직입니다**<br>Arch + A.T 를 같이 잡아 눈썹 굵기를 유지한 채 위치만 옮겨 보는 식으로 씁니다<br>끄면 다시 한 줄 선택으로 돌아옵니다 |
| **사진 이동** | 잠금이 풀린 상태에서 **선이 아닌 곳을 한 손가락으로 끌면** 사진이 사방으로 자유롭게 움직입니다 |
| **사진 확대·회전** | **두 손가락** 핀치 / 비틀기 |
| **사진 보정 버튼** | 아래 오른쪽 `줌 · 위아래 · 좌우 · 밸런스` — 누르면 **바로 아래 좌우 드래그 바**가 사진 조절로 바뀝니다<br>같은 버튼을 다시 누르면 선 조절로 돌아옵니다 |
| **사진 잠금** | `🔒 사진잠금` — 누르면 사진이 완전히 고정되고 **사진 보정 버튼이 반투명으로 잠깁니다**<br>이 상태에서는 화면 어디를 끌어도 **선만** 움직입니다 (시술 중 미세조정)<br>다시 누르면 버튼이 밝아지고 사진을 움직일 수 있습니다 |
| **바 선택 · 방향 조절** | 화면의 바를 **탭하면 선택** → 드래그 바 양끝 버튼으로 미세 이동<br>가로 바는 `▼ ▲` (위아래만), 세로 바는 `◀ ▶` (좌우만)<br>세로 바는 Center 기준으로 **좌우 대칭** 이동 |
| **전체라인** | `여러라인` 을 켜면 따라 나오는 후속 버튼. 화면에 보이는 **모든 선을 한 번에 선택** → 전체를 통째로 이동 |
| 전체 선 숨김 | 캔버스 좌상단 `모든 라인 숨김` — 지금 보이는 선 전부 숨김/복원 |
| V형 기본구조 | **왼쪽 레일 맨 아래** `V Center Pivot`(기준점 높이) / `V Angle`(벌어짐 각도) |
| 프리셋 | **왼쪽 아래 첫 버튼** `프리셋` → 로드 / 현재 설정 저장 / 이름변경 / 삭제 |
| **즐겨찾기 ★** (v1.28.0) | 프리셋 창에서 이름 왼쪽의 **★ 를 누르면 즐겨찾기**가 됩니다 (**최대 3개**)<br>즐겨찾기한 것은 프리셋 버튼 옆에 **바로 버튼으로 나와** 창을 열지 않고 한 번에 올릴 수 있습니다<br>지정한 개수만큼만 나오고, 하나도 없으면 `프리셋` 버튼만 보입니다 |
| 결과 저장 | `사진저장` — **화면 가운데 아래**, 사진잠금 왼쪽. 사진 + 가이드라인을 PNG로 저장 |
| 사진 바꾸기 | `사진변경` — **오른쪽 끝 맨 위**, 위아래 드래그 바 위쪽입니다 |
| 초기화 | **캔버스 왼쪽 위 칩 줄 맨 오른쪽** (v1.28.0) — `밸런스` 에서 한 칸 띄운 붉은 글자<br>시술 중 손이 가지 않는 위쪽 가장자리라 실수로 눌릴 일이 거의 없습니다. 잘못 눌러도 `되돌리기` 로 복구됩니다 |
| **다시 실행** | `↷ 다시 실행` — 되돌리기 바로 위. 되돌린 것을 앞으로 다시 적용합니다<br>새로 무언가를 고치면 다시 실행 기록은 사라집니다 |
| **한 / 영** | 왼쪽 레일 맨 위 `한/영` — 모든 버튼 문구가 한국어 ↔ 영어로 바뀝니다 (다른 언어 추가 예정) |
| **밸런스 판정** | `밸런스` — 사진에 그려진 실제 드로잉을 읽어 **좌우가 같은 높이인지 판정**합니다<br>먼저 `기준 L/R` 로 **어느 쪽을 기준으로 삼을지** 고릅니다 (한 번 고르면 다음에도 유지, 언제든 변경 가능)<br>기준이 아닌 쪽에서 어긋난 선만 **빨간색으로 굵게** 표시됩니다 → 그 부분만 다시 그리면 됩니다<br>선을 움직이면 판정은 초기화됩니다 (옛 결과를 그대로 두지 않기 위해) |
| **되돌리기** | `↶ 되돌리기` — 오른쪽, 위아래 드래그 바 바로 위<br>**직전 작업 하나만** 되돌립니다. 다시 누르면 그 전 작업<br>드래그 한 번 · 슬라이더 한 번 · 버튼 한 번이 각각 한 단계입니다<br>선을 탭만 한 경우처럼 값이 안 바뀐 동작은 단계로 쌓이지 않습니다 |
| **화면 가로 고정** | **작업 화면은 가로 전용입니다.** 화면 회전 잠금을 켜 둬도 사진을 넣는 순간 가로로 나옵니다<br>안드로이드 설치앱은 **폰 화면 자체를** 가로로 돌리고, 아이폰·아이패드는 앱 화면만 90° 돌립니다 |
| **사진 넣는 동선** (v1.28.0) | **첫 화면(사진 선택)은 세로 그대로**입니다 — iOS 사진 창이 세로로 뜨기 때문에 그대로 이어서 고르면 됩니다<br>사진을 넣으면 **편집 화면부터 가로**로 바뀝니다<br>작업 중 `사진변경` 을 누르면 **화면은 가로 그대로 두고 어둡게만** 낮춥니다. 위에 뜬 사진 창만 보고 고르시면 되고, 닫으면 원래 밝기로 돌아옵니다 |

## 5. AI 얼굴 자동 인식

사진을 고르면 **기기 안에서** 얼굴 랜드마크를 인식해 자동 정렬합니다
(동공 수평 맞춤 → 중앙 정렬 → 확대 → Inner/Outer/눈썹 라인 자동 배치).

- 얼굴은 **메인 작업 영역(캔버스 왼쪽 ~ 오른쪽 드래그 바)의 가로 한가운데 · 세로 55%** 에 맞춰집니다.
- **가로 가이드 선은 오른쪽 드래그 바를 넘어가지 않습니다** — 컨트롤 위로 선이 튀어나오지 않도록.
- 모델은 **처음 한 번만** 인터넷에서 내려받고, 이후에는 캐시되어 오프라인 동작합니다.
- 사진은 **어디에도 업로드되지 않습니다.** 전부 브라우저 안에서 처리됩니다.
- 인식이 안 되면 사진을 손가락으로 직접 밀고 확대해 눈높이를 맞추면 됩니다.

**v1.22.0 부터 — 선마다 AI 자동 위치**

왼쪽 레일에서 선을 켤 때, 미리 정해둔 자리가 아니라 **그 사진의 실제 눈썹을 보고** 그 선의 자리로 올라갑니다.
(앞머리 밑 · 앞머리 두께 · 산 · 산 두께 · 꼬리 각각 따로 계산합니다.)

**v1.25.0 부터 — 사진 크기와 무관한 일정 배치**

사진이 크든 작든 **눈 크기 · 눈 위치 · 꼬리 끝**이 항상 비슷한 자리에 오도록 맞춥니다.
양쪽 꼬리가 버튼에 잘리지 않도록 여백도 함께 확보합니다.

**v1.25.0 부터 — 프리셋 얼굴 자동 환산**

프리셋에는 저장 당시의 **얼굴 기준틀**(눈 사이 폭 · 눈–눈썹 거리)이 함께 저장됩니다.
불러올 때 지금 고객의 얼굴 폭 · 눈썹 높이에 맞춰 **모든 선을 자동으로 크게/작게 환산**합니다.
적용 중인 프리셋 버튼은 색이 달라져 어떤 프리셋이 올라가 있는지 바로 보입니다.
(기준틀이 없던 옛 프리셋은 예전처럼 그대로 올라옵니다.)

### 자체 서버 AI를 붙이고 싶다면

`app.js` 맨 위 `SERVER_AI_ENDPOINT` 에 주소를 넣으세요.
`POST { imageUrl }` → `FaceAnalysisResult` JSON 을 돌려주면 됩니다.
(기존 Manus 서버의 `brow.analyzeFace` 와 같은 형식)

## 6. 앱스토어 / 구글플레이 등록 (나중 단계)

이 웹앱 코드를 **다시 짤 필요 없이** 그대로 네이티브 앱으로 감쌀 수 있습니다.

```bash
npm init -y
npm i @capacitor/core @capacitor/ios @capacitor/android
npm i -D @capacitor/cli
npx cap init "Perfect Brow" com.perfectbrow.app --web-dir=.
npx cap add ios
npx cap add android
npx cap open ios        # Xcode 에서 빌드 → App Store Connect 업로드
npx cap open android    # Android Studio 에서 빌드 → Play Console 업로드
```

필요한 것: Xcode(맥), Apple Developer Program 연 $99, Google Play Console 1회 $25.
심사는 보통 1~3일 걸립니다.

## 8. 원본(Manus Expo 프로젝트) 대비 달라진 점

원본 `perfect-brow-source` 폴더는 **하나도 건드리지 않았습니다.**

**고친 것**

- 라인 직접 드래그 — 원본은 `PanResponder`를 import만 하고 미구현, SVG가 `pointerEvents="none"` 이라 아예 동작 불가였음
- 프리셋 저장 — 원본은 저장 모달을 여는 버튼이 없었고, `loadPresets`가 매번 저장소를 기본값으로 덮어써서 저장분이 사라졌음
- 줌 자동 중앙정렬 단위 오류 — 정규화 변수에 픽셀값을 넣고 렌더링에서 캔버스 폭을 또 곱해 약 400배 어긋남
- 핀치/드래그 튐 — 누적 이동량을 매 프레임 델타처럼 더하던 문제
- 네이티브에서 안 그려지던 요소 — 소문자 `<circle> <rect> <path>` 사용으로 눈 가이드·라벨·기준점이 웹에서만 보였음
- Front / F.T 가 같은 길이로 그려지던 문제
- 라벨 겹침 — 세로/가로 라벨 자동 회피 배치
- 화면 회전·리사이즈 미대응 (모듈 로드 시점에 화면 크기를 한 번만 읽던 문제)

**뺀 것**

- Manus 종속 전부 (forge.manus.ai LLM, manus.computer 터널, Manus OAuth, TiDB, iframe 브리지)
- 사용되지 않던 죽은 코드 (h4, arch, spacing, lineColor, lineOpacity, pivotPointY 등)

**더한 것**

- 결과 이미지 PNG 저장
- 오프라인 실행 · 홈 화면 앱 설치
- 가로 전용 양손 레이아웃 — 왼쪽 라인 레일 / 사진이 화면의 90% 이상 / 오른쪽·아래 오버레이 도크
